# Calorie Counter
This is an application that tracks your daily calorie intake.

## Features
**Add items:** Enter a food name and its calorie count to log your meal.
**Live Calculation:** It automaticly  updates your total calories.
**Delete item:** Easily remove specific food items from your list.
**Persistent Data:** `LocalStorage` has been used so your data stays saved even if you refresh your page.
**Reset Features:** You can clear your entire list with a single click to start a fresh day.


## Project Structure
The project is made up of three files:
`Index.html` - The structure of the page (Styled using Tailwind)
`script.js` - The JavaScript logic that runs the application.
`README.md` - Documentation and instruction.

## Setup Instruction
To run this project in your local computer, follow these simple steps:

1. Open VS Code (or whatever code editor you prefer).
2. Create your project folder on your computer and open it in VS Code.
3. Create the files: Create `index.html` and `script.js` directly inside   that folder.
4. Paste the code into those files and save them.
5. Run it: Instead of just double-clicking the file in your computer folders, the best way to open it is to use the Live Server extension in VS Code. Just right-click your index.html file and select "Open with Live Server".
